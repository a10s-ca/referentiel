# Statut de l'Offre

Vocabulaire contrôlé pour les statuts d'une offre.

|            |                    |
| ---------- | ------------------ |
| **Type**   | `enum (of string)` |
| **Requis** | Non                |

Doit être un de:
* "EventScheduled"
* "EventCancelled"
* "EventRescheduled"
* "EventPostponed"
* "EventMovedOnline"
